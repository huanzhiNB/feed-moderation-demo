# CLAUDE.md

This repo is a timed take-home exercise (see `README.md`): build an iOS app around one
screen — an infinite, snap-scrolling feed of WebView-hosted content, with creator blocking
and content reporting, against the mock server in `mock/`. Budget is ~6 focused hours. These
rules exist so Claude's help stays inside what actually earns points, instead of polishing
things nobody is grading.

- @SCOPE.md — platform, deployment target, third-party libraries, what's out of scope
- @ARCHITECTURE.md — MVVM/Router pattern, DI, and the stream-derivation rule the grading
  rubric weights most
- @SWIFT-STYLE.md — language, code quality, memory management, concurrency, style
- @MOCK-SERVER.md — what's fixed about `mock/`, and how to reach it from the simulator
- @TESTING.md — what to test and what not to
- @WORKING-STYLE.md — scope discipline and submission deliverables
