# Working style for this repo

- This is a scoped, timed exercise, not a production codebase — favor the smallest correct
  implementation of each hard requirement over extensibility, abstractions, or handling cases
  the mock server can't produce.
- The submission needs a short app-level README (how to run, what was cut, frame-timing
  numbers, behavior on moderation-call failure) and a ~1 minute screen recording — keep these
  in mind as deliverables, not afterthoughts, when a task is close to "done."
- This repo will be submitted by forking and sending back a URL — never push to a remote or
  open a PR without being explicitly asked to.
